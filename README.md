# 日語水果道場（にほんご・フルーツどうじょう）

可愛風格的日語學習切水果遊戲。每題會從三條路線各飛出一顆帶著選項的水果，用手指劃過正確答案的那一顆；切對得分，切錯會爆炸並扣分，每局最後有魔王。

## 內容

- 五個等級：平假名、片假名、濁音・拗音、基礎單字（約 N5）、中等單字（約 N4）
- 題型：看假名選羅馬拼音、看日文選中文、看中文選日文、看漢字選讀音，以及可選的聽力題
- 三種速度：輕鬆、普通、困難
- 一局 10 題（7 題一般題加魔王 3 題），每題有倒數計時；前面答錯的字會由魔王再考一次
- 結算畫面列出本局所有題目，可把想記的字加入筆記本，再用筆記本的字玩一局客製化特訓
- 避免漢字提示模式：題目是中文時，答案只顯示假名，題目與答案不會同時出現漢字
- 忍者角色：可選擇造型，砍水果時忍者會從畫面下方飛到水果旁揮刀
- 等級制度：每局得分會累積，升級後解鎖新的忍者造型
- 靜音模式：完全不發出聲音，也不會出現聽力題
- 進度存在瀏覽器的 localStorage，不需要帳號，也不蒐集任何資料

## 操作

- 手機：用手指劃過（或點一下）正確答案的水果
- 電腦：按住滑鼠劃過水果，或按數字鍵 1～3；Esc 暫停

## 執行

純靜態網頁，沒有建置步驟。直接開啟 `index.html`，或用任何靜態伺服器：

```
python3 -m http.server 8000
```

題庫在 `js/data.js`，遊戲邏輯在 `js/game.js`，魔王圖片在 `assets/boss.png`，忍者動作圖在 `assets/ninja.png`（各色造型由程式換色產生），長頸鹿忍者在 `assets/giraffe.png`。
