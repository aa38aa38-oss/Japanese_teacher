# 日語小飛機（にほんご・フライト）

可愛風格的日語學習射擊遊戲。帶著選項的小怪物從上方逼近，把飛機移到正確答案下方發射；答錯或來不及就會扣血，每關最後有魔王。

## 內容

- 五個等級：平假名、片假名、濁音・拗音、基礎單字（約 N5）、中等單字（約 N4）
- 題型：看假名選羅馬拼音、看日文選中文、看中文選日文、看漢字選讀音，以及可選的聽力題
- 三種速度：輕鬆、普通、困難
- 一局 10 題（7 題一般題加魔王 3 題），每題有倒數計時；前面答錯的字會由魔王再考一次
- 結算畫面列出本局所有題目，可把想記的字加入筆記本，再用筆記本的字玩一局客製化特訓
- 進度存在瀏覽器的 localStorage，不需要帳號，也不蒐集任何資料

## 操作

- 手機：拖曳移動飛機，放開手指發射（也可以直接點答案所在的路線）
- 電腦：方向鍵移動、空白鍵發射；數字鍵 1～4 可直接飛到該路線並發射；Esc 暫停

## 執行

純靜態網頁，沒有建置步驟。直接開啟 `index.html`，或用任何靜態伺服器：

```
python3 -m http.server 8000
```

題庫在 `js/data.js`，遊戲邏輯在 `js/game.js`，魔王圖片在 `assets/boss.png`。
